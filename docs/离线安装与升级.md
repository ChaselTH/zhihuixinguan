# 智慧信管 0.4.0-rc.2：离线安装与升级

本包是工作流重构联调版，数据库 schema 仍为 10。已通过 Windows 本地合成数据回归和安装器模拟；麒麟及 Win7 实际 IE 尚未实测，不应仅凭本包直接投产。

## 选择安装包

使用 U 盘完整目录 `zhihui-xinguan-offline-0.4.0-rc.2-kylin`。其中包含 `install.sh`、`payload`、两种 Linux CPU 架构运行时和 `SHA256SUMS`，安装及启动无需联网、另装 Java、Node 或数据库。`SOURCE_COMMIT` 是构建所用源码提交。本包不含业务表格、数据库、私人初始化密码；升级时沿用工作电脑原有账号、密码和本地配置。

## 更新已有安装

1. 在旧服务前台窗口按 Ctrl+C，确认旧服务已停止。无需卸载旧版。
2. 将 U 盘完整安装包目录复制到麒麟本地磁盘，在该目录打开终端。
3. 如果旧安装是默认目录，执行：

```bash
bash install.sh
cd "$HOME/ZhihuiXinguan-PR0"
./start.sh
```

如旧安装位于其他位置，先确认原 `start.sh` 所在的**绝对路径**，再执行 `INSTALL_DIR="/实际旧安装绝对路径" bash install.sh`。不要照抄占位路径，也不要把 U 盘包目录当作旧安装目录。

启动时询问端口，回车使用 2874，已占用可另选。服务在前台运行，Ctrl+C 关闭；另开终端进入安装目录执行 `./start.sh status` 查看状态。浏览器访问 `http://麒麟电脑IP:所选端口/`，网页应显示 `V0.4.0-rc.2`，`/health` 应返回 `SCHEMA=10`。升级后使用原账号登录。

## 首次空库安装

通用包不含实际初始化账号。安装完成后，在**麒麟本机**将安装目录中的 `bootstrap.example.properties` 复制为 `bootstrap.local.properties`，填写获准的统一认证号和初始密码，将文件权限设为仅本人可读（例如 `chmod 600 bootstrap.local.properties`），再首次启动。初始化配置只用于空账号库，不会重置现有账号。不要把该文件上传 GitHub 或经公开渠道发送。

## 数据保留与异常处理

- 安装器先校验归档，在暂存目录复制旧 `data` 并检查迁移；通过后才替换旧目录。成功升级会在安装父目录留下 `.zhihui-xinguan-backup-时间-编号` 完整旧版备份，不自动删除。
- 若校验、迁移或安装失败，立即停止并保全原安装、暂存目录及错误信息。不要清空数据库、修改迁移校验值或覆盖备份。
- 备份应包含整个 `data` 目录，以及 `platform/initial-password.key` 和 `.bak`（如存在）；不能只备份 `records.mv.db`。
- 本版未新增迁移。经验证的旧 schema 8 可升级至 schema 10；已是 schema 10 的正式旧版数据保留。曾运行未修复测试迁移而出现校验冲突时，保全原库并联系维护人，不强行绕过。
- 不要用旧程序直接运行升级后的 schema 10 库。回退应恢复升级前完整备份，并先保全升级后新增的业务数据。

## 本版人工验收

按角色完整走一条脱敏测试记录：操作员填写／保存／提交 → 支行复核员通过或填写原因退回 → 分行管理员终审或退回；确认终审前正式统计和导出不变，终审后同步更新。再测已完成旧行退回、复核员自行修订、无原操作员旧行、个人通知全部已读、来源页面返回及跨支行权限。详细步骤见包同级《角色验收步骤.md》。

实际麒麟 CPU／系统、实际 Win7 IE／文档模式、正式数据量性能、数据安全提示文本和行内传输保护仍需现场验收。当前 HTTP 未加密，仅可在获准的隔离内网联调；不要直接暴露到公网。
