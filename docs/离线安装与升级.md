# 智慧信管 0.3.0-rc.12：离线安装与升级

本包为两级审核联调测试版，应用 0.3.0-rc.12，数据库 schema 10。面向麒麟断网安装和局域网访问，实际麒麟／CPU、Win7 旧 IE 仍须现场验收。rc.12 在 rc.11 基础上调整通知和复核交互，schema 仍为 10，无新增迁移，可直接覆盖升级。

## 选择安装包

使用 U 盘的 `zhihui-xinguan-offline-0.3.0-rc.12-kylin` 完整目录，包含 install.sh、payload、两种架构 Java、模板和校验清单。无需联网，无需另装 Java、数据库或 Node。旧包保留，本次使用 rc.12。

SOURCE_COMMIT 记录源码版本。包不包含开发电脑业务数据库；私人初始化文件仅首次空库使用，不重置旧库账号。整个私人包须按凭据保管，不公开上传或转发。

## 更新旧安装

1. 在麒麟旧服务窗口按 Ctrl+C，确认停止；无需先卸载。
2. 将 U 盘完整 rc.12 安装目录复制到麒麟本地，不要只复制 install.sh。
3. 在复制后的包目录打开终端，执行：

```bash
bash install.sh
cd "$HOME/ZhihuiXinguan-PR0"
./start.sh
```

默认目标沿用原 ZhihuiXinguan-PR0。如果旧安装位于其他位置，先确认原 start.sh 所在目录，再指定原安装绝对路径：

```bash
INSTALL_DIR="/原安装目录的绝对路径" bash install.sh
```

不要照抄占位路径，不要把 U 盘包目录当成原安装目录。

启动时询问端口，回车使用 2874，占用时可另选。前台运行，Ctrl+C 关闭；另开终端进入安装目录执行 `./start.sh status` 查看状态。浏览器访问 http://麒麟电脑IP:所选端口/，网页应显示 V0.3.0-rc.12，/health 应返回 SCHEMA=10。升级后重新登录，原账号密码不变。

## 保留内容与失败恢复

- 保留账号、机构、历史月份、正式内容、私人草稿、提交快照、审计、必填规则和截止日期，不导入开发电脑测试数据。
- 安装器校验文件后复制旧 data 到暂存区验证迁移；成功才替换，完整旧版备份保存在安装父目录 .zhihui-xinguan-backup-时间-编号，不自动删除。
- 失败立即停止，保留原安装、暂存和错误。不要删除数据库或迁移标记，不修改校验值来绕过失败。
- 备份须包括整个 data、platform/initial-password.key 和 .bak，不可只复制 records.mv.db。密钥遗失须保全目录并联系维护人。
- rc.10 发布包的 schema 8 可升级。本版新增 V009/V010，V001～V008 不改；旧正式内容保留原完成口径，旧待审进入两级审核，不虚构历史终审。
- 原版同一行多份待审快照全部保留；复核员先明确退回重复任务，保留唯一待审后再批准。
- 若曾使用未修复 PR #12 的 schema 10 测试库，本版会因迁移校验不同拒绝启动。保全并从已验证的 schema 8 升级前备份在隔离目录重做；无备份请联系维护人设计兼容迁移，不改 checksum、不清库。
- schema 10 不可直接交给 rc.10 或更早程序运行。回退须恢复升级前完整备份，并先保全升级后新增数据。

## 本版重点测试

1. 分行管理员进入数据更新，选择所属月份后上传单类文件、多工作表或多文件；系统按表头识别多重预警、负面闭环、交叉违约，一至三类共用一个入口。
2. 全批归入选择的月份；表内时间仅为来源信息。核对新增／重复／更新汇总，选择保留或覆盖。未知非空页、错误表头整批报错，有审核任务的行禁止覆盖。
3. 上传黄色列的预填值为候选，支行复核前后都不提前发布；独立支行复核员确认后由分行终审。唯一分行管理员可终审自己的上传候选。
4. 操作员在本支行待处理表填写 → 保存私人草稿 → 预览差异 → 确认提交。复核员优先看到待复核行，批准只送分行，不直接更新正式内容。
5. 支行复核后，该行移出支行业务明细；旧链接仅可看精简流程回执。分行终审才更新正式统计和导出。支行不能通过“查看全部”访问已完成行。
6. 支行管理员／复核员本人填写经预览确认后送分行终审；分行管理员本人修改经确认直接发布，超级管理员不能填报。
7. 分行可退回待终审行或重开已完成行并填写原因，原正式值保留。操作员只恢复当前退回行；原内容正确时使用“核对后原值重提”，仍走完整审核。
8. 必填规则保留。空白不阻止提交和审核，但终审后缺必填项仍不计完成，回到支行待处理范围；核对进度、超期、底色和导出一致。
9. 首页分为统计和三类待处理清单；时间、机构、搜索、分页、顶部／底部滚动及授权导出仍可用。已提交草稿不可继续改，部分退回不可恢复其他在途行。
10. 两级在途任务均阻止按月删除；重复提交、审批、旧预览不应重复生效或部分写入。核对通知自动已读、支行审计隔离和历史保留。

现场核对账号、月份、记录数、旧反馈、截止日期和原设置。用实际 IE 检查登录、下拉、导入、保存、审批、滚动及下载；本地模拟不是实机通过。

## 开发与安全边界

发布前运行 node tools/build.mjs --test --offline 和 node tests/install-smoke.mjs。完整测试需要本地 Git 旧提交对象和依赖缓存；源码快照没有历史，不能独立运行历史升级回归。麒麟安装和启动不需要 Git／Node。

不启用云端 CI，不重启开发电脑现有服务。正式安全文案、其他行内模板和实机验收仍待补充，无风险按钮未实现。HTTP 未加密，仅供获准隔离内网联调，正式推广前须确认行内传输保护。
