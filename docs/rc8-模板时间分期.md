# rc.8：删除额外列，按模板时间分期

版本 0.3.0-rc.8 / schema 7。当前维护人实施，不分配另一台 AI 任务，不启用云端 CI。

## 本轮调整

- 三类详细清单删除末尾额外的“期次／历史保留信息”表头及单元格，同步空表跨列数。原模板列的顺序、黄色填报列及既有流程入口不变；导出和空模板仍是原模板列数。
- 多重预警使用 W 列“时间顺序”；负面闭环使用 M 列“时间顺序”。支持有效月份 `2026-09` 或起止日期 `20260901-20260915`，同一工作表可包含多个月份／时间段，逐行归档。
- 交叉违约继续使用 L 列“违约首次出现时间”，按该有效日期的所属月份归档，兼容原文本日期、Excel 日期和有缓存的日期公式。
- 删除文件名／公共月份／补充期次的解析兜底。缺失或无效时间定位到原工作表、行和列；任一行失败整批不暂存、不导入，不默认为当前月份。旧解析器参数仅保留调用兼容，不参与分期。
- 内部仍保存规范化时间用于查询、截止日期、去重和导出筛选；日期区间跨月时保持现有区间相交筛选，不新增业务列。同一日期的不同格式和文件改名不产生新分期。

## 兼容与数据保留

没有新数据库迁移，不改 V001～V007，不自动清理或重算历史数据。原模板时间字段仍保留；已有数据、反馈填写、截止日期、工作流快照和库内历史附加信息均保留。移除的是网页附加展示列，不是删除数据。此前版本正常导入的规范化时间不变，不使其草稿或审批凭据失效；旧版本特殊迁移的数据如需校正，应核对原表后单独处理，不推测原日期。

## 验证范围

执行 `node tools/build.mjs --test --offline` 和 `node tests/install-smoke.mjs`。新增回归涵盖：三类明细的表头／行宽／空状态、原字段保留，缺失及无效时间、反向日期区间、文件名与旧上传参数不能替代原列、同表多月份、同工作簿三类不同月份、按月及年度展示、模板宽度导出、截止日期分组、改名重传识别重复以及整批拒绝。
