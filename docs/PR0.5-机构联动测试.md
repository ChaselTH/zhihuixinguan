# PR0.5 人员机构联动测试记录

版本：0.3.0-pr0.5。本次只调整添加／修改人员时的机构联动，不修改账号库结构、已有账号、密码及业务记录。

## 交互规则

- 选择分行管理员，机构选择隐藏，后台自动归属分行。
- 选择支行管理员、操作员、复核员，显示所属支行；仅显示当前管理员有权管理的支行，列表不包含分行。
- 切换到分行管理员再切回支行角色，保留之前选择的支行。支行未选时提示选择，不创建账号。
- 编辑已有人员和新增人员使用相同规则。页面联动使用本地脚本，不请求外部资源；禁用脚本时可按提示选择支行，后台归属与权限校验仍有效。

## 自动验证

- identity-form.test.mjs：12 项检查通过，覆盖显示／隐藏、禁用字段不提交、切换保留支行、键盘切换、提交同步、旧 IE 事件分支及页面恢复。使用隔离 DOM 模拟，不等于旧 IE 实机验证。
- HttpSmokeTest：134 项检查通过，新增验证分行无机构字段即可创建、分行编辑忽略残留支行值、九支行选项、缺少支行错误回显、支行角色不能归属分行、本支行选项限制及本地脚本可访问；原有权限和业务接口回归通过。
- FoundationTest：183 项检查通过。
- IdentityTest：53 项检查通过。

合计 382 项检查通过。麒麟和 Win7 IE 仍需实机测试；本轮未使用实际用户账号进行新增、删除或修改操作。

## 安装验收

停止旧服务后运行新包 install.sh 更新同一个安装目录，无需卸载。登录后检查网页版本为 V0.3.0-pr0.5，在添加人员页面切换角色，确认分行管理员没有机构下拉，其余角色可选择授权支行。
