# PR0.6 本地初始化与源码提交测试记录

版本：0.3.0-pr0.6；日期：2026-09-14。

## 本次变化

- 从源码、说明和测试中移除个人初始化认证号及密码。普通构建只有空白 bootstrap.example.properties；Git 忽略 bootstrap.local.properties。
- 首次空库启动由本地配置建立超级管理员，保留认证号前导零及免首次改密。配置缺失、内容无效、超大或非普通文件时拒绝初始化，不提供通用默认账号。
- 账号库已有用户时，不读取、不要求该文件，不重置密码。修改过的密码在重启及升级后保持不变。
- 离线打包通过可选 BootstrapConfig 参数显式附带私有文件；升级优先保留旧配置。带凭据的私人离线包不得发布到 GitHub。
