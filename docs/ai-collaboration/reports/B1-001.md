## 路由与表单契约

### GET

| URL | 用途 | 主要查询参数 |
| --- | --- | --- |
| `/workflow` | 按角色显示工作台 | `notice` |
| `/workflow/edit` | 草稿编辑或授权直接修改 | `dataset`、`organization`、`from`、`through`、`page`、`draft`、`prior` |
| `/workflow/preview` | 恢复本人服务端预览 | `id` |
| `/workflow/submissions` | 我的提交／授权提交列表 | `dataset`、`organization`、`state`、`from`、`through`、`mine`、`page` |
| `/workflow/reviews` | 本支行复核待办 | 同列表参数，服务端强制待复核状态和当前机构 |
| `/workflow/submission` | 授权提交单不可变详情 | `id` |

### POST

| URL | 用途 | 业务参数（均另带 `csrf`） |
| --- | --- | --- |
| `/workflow/draft/save` | 保存完整草稿或保存后预览 | `dataset`、`draftId`、`draftVersion`、`priorSubmissionId`、`requestId`、`intent=save/preview`、当前页 `idN/versionN/value_N_字段键` |
| `/workflow/direct/preview` | 三类授权角色直接修改预览 | `dataset`、当前页记录及字段 |
| `/workflow/confirm` | 确认服务端预览 | 仅 `previewId`、`requestId` |
| `/workflow/review/approve` | 批准整单 | `submissionId`、`requestId` |
| `/workflow/review/reject` | 退回整单 | `submissionId`、`reason`、`requestId` |

身份、角色和机构不从表单构建；构造器保持约定的 `WorkflowRoutes(PlatformStore store, String version)`，入口方法为：

```java
boolean get(HttpExchange x, AuthService.Session session, Map<String,String> query) throws Exception;
boolean post(HttpExchange x, AuthService.Session session, Map<String,String> form) throws Exception;
```
