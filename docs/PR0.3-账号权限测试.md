# PR0.3 账号权限测试记录

本轮使用 Windows 本地 JDK 17 / Node 24，所有业务与新建人员均为隔离测试数据；不操作用户正式账号库。

- FoundationTest：183 项检查通过，保留导入、字段、基础权限、版本冲突、数据迁移测试。
- HttpSmokeTest：94 项检查通过。真实启动独立 HTTP 服务，覆盖首次改密门禁、统一认证号登录、五角色用户创建、角色不由登录表单决定、层级用户管理、重复账号拒绝、同级／上级修改阻断、停用与密码重置、会话失效、跨支行查看与导出阻断、操作员直写阻断，以及原三表导入／保存／导出流程。
- IdentityTest：29 项检查通过，验证指定超管认证号前导零保留、仅首次初始化、密码改变后重启不重置、随机初始密码、事务内身份版本复查、首次改密、停用账号禁用、机构转移不搬动业务数据、口令不记入审计、登录错误限速。

合计 306 项检查通过。真实麒麟及 Win7 IE 仍需实机验收；权限申请、通知、操作员草稿与复核不在本版实现范围。本轮未进行浏览器自动点击或截图验收。
