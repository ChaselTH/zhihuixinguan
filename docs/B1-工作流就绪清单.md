公共层是持久化状态转换和安全校验的唯一入口。B 的工作流服务负责组织编辑、预览、确认、待办、复核及错误交互；界面可以提前判断，但不能代替公共层核验。调用命令时只传会话得到的 ActorContext，不接受客户端声称的操作人、角色、机构或审批状态。

B 需要路由、公共导航或测试注册时，提交明确的接入清单，由公共维护人作小提交接入。不要等最终打包才首次接入路由；B1 合并前须完成 HTTP 与五角色关键链路验证。

## 4. 公共维护人需先提供的契约

以下描述能力及约束，不是已存在的方法名。公共补丁必须交付真实类名、方法签名、返回值、错误类型、调用示例和可执行测试，不能只再添加一组空接口。

1. **私人草稿。** 保存、列出、恢复本人草稿，绑定当前账号、机构和数据集；草稿自身版本防止多标签覆盖。查询和更新都校验 owner，管理员的全行正式数据查看权不自动授予他人私人草稿读取权。停用或转机构后不能继续用旧身份提交原机构草稿。
2. **服务端差异预览。** 从已授权正式记录生成字段名、原值、新值、记录版本和变更条数；只允许 DatasetSchema 黄色字段。确认凭据绑定本人、操作类型、草稿版本或规范化内容、正式行版本，并有有效期。预览本身不创建审批待办。
3. **确认与提交快照。** 确认时重新验证预览基线，冻结原值／新值／行版本／提交人／期次等快照，生成待审单、审计及通知；任一步失败均不留下半张提交单。后续草稿修改不改变快照。同一人同一记录已有待审变更时不重复提交。
4. **授权待办和详情。** 列出本人提交及本支行复核待办，支持明确的状态、时间和分页参数；按现有角色约束提供已提交单的查询。无权访问时不得在详情、错误或通知中泄露其他机构内容。
5. **批准事务。** 复核员只能批准本支行待审单，校验当前身份、单据状态、快照及所有行版本。正式值／行版本、审批结果、审计、通知事件和接收人一起提交；任一记录冲突或写入失败整单回滚。不能先调用会自行提交事务的 publishDirect，再另写审批状态。
6. **退回事务。** 原因必填，审批状态、决定、审计和通知同时落库，不修改正式值；重新提交建立新单并关联旧单，不原地改历史快照。失败后仍可安全重试。
7. **直接提交确认事务。** 分行管理员、支行管理员、复核员可用，超级管理员及操作员不可用。复用已有正式写入校验和批量原子性，补预览绑定、直接变更单、审计和通知一致性；这是本人直接修改，不是代替操作员审批。
8. **通知与个人已读。** 由服务端决定接收人，事件去重；支持本人的列表、未读数及幂等已读。业务通知与业务变更同事务持久化，界面读取失败不撤销已完成业务。已读不等于已审批，读取及详情跳转仍核验当前机构权限，通知不带密码或完整敏感业务明细。
9. **错误及重试约定。** 区分无权限、确认失效、版本冲突、重复请求内容变化、已处理和事务失败。同一请求重复执行返回已提交结果；不同审批请求竞争同一单只能有一个决定。冲突时不自动覆盖，不为了记录 CONFLICT 而误提交部分正式修改。
10. **迁移与集成。** 若需结构变化，先提供顺序迁移器和新增迁移；保留 V001 校验及旧数据。交付事务故障注入、并发及升级测试。B 不获取裸数据库连接或任意 SQL／提交事务权限。

| 编号 | 测试场景 | 期望结果／主测负责人 |

| W01 | 同支行两名操作员互查、互改草稿；管理员尝试打开他人私人草稿 | 均无权读取／修改；A 平台测试，B 入口测试 |
| W02 | 保存草稿、注销、重新登录恢复；多标签持旧草稿版本保存 | 可恢复本人内容；旧版本不能静默覆盖；A/B |
| W03 | 保存草稿、生成预览、确认待审、退回 | 正式值、正式完成率及导出均不提前变化；A/B |
| W04 | 预览后改草稿／正式值；篡改确认内容、账号、机构、字段或凭据 | 确认拒绝或要求重新预览，不能提交未确认内容；A/B |
| W05 | 提交后改草稿、重复确认、换请求号重复提交同一待审记录 | 快照不可变，不产生重复待审单／通知；A/B |
| W06 | 两位复核员并发批准，或批准与退回竞争 | 单据只有一个有效决定，正式值最多生效一次；A 并发测试，B 提示测试 |
| W07 | 一单多行中一行冲突，或批准中途数据库写入故障 | 所有正式修改、决定、审计、通知均回滚；A 故障注入，B 整单失败提示 |
| W08 | 退回缺少原因；合法退回后修改并重新提交 | 缺原因拒绝；旧单保留，新单关联，正式值不变；A/B |
| W09 | 三种直接修改角色预览并确认；操作员或超管绕过界面直调 | 合法修改原子生效并留痕；越权拒绝；A/B |

| W11 | 用户停用、转支行、改角色后持旧会话／确认／草稿操作 | 服务端拒绝旧授权；不靠隐藏按钮保护；A/B |

| W13 | 重启后恢复草稿、待审单、决定及已读状态；旧库升级 | 已提交事务持久保留，不重放生效、不丢旧数据；A 平台及升级测试 |
