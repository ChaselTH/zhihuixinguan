# 智慧信管 0.4.0-rc.2 发布检查

本版是联调候选，不是正式投产批准。源码提交以包内 `SOURCE_COMMIT` 为准；数据库 schema 保持 10。未启用或运行 GitHub CI。

## 变更核对

- 初始填报仅操作员发起；支行复核员通过后送分行，分行终审才写正式值。任一退回先到上一层，私人草稿和待审内容不进入正式统计／导出。
- 支行复核员可保存分行退回行的本人修订或直接提交；历史已完成行重开先到复核员，没有有效原操作员时不随机分配。
- 工作流使用清晰的待办和进度表；复核表格首列单行通过／退回，批量操作收敛为两个按钮。操作记录和行历史为表格，显示操作人、阶段和原因。
- 通知按个人授权范围显示，点击自动已读，支持全部已读；跨页面返回使用站内明确来源，保留筛选条件。旧版直接修改和原值重提 HTTP 入口已关闭。
- 分行管理员清单只读，通过终审或退回要求修改；支行管理员只读业务，不替代操作员或复核员。
