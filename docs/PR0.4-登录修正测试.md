# PR0.4 登录与改密修正测试记录

版本：0.3.0-pr0.4。使用 Windows 本地 JDK 17，全部自动测试在隔离账号库和虚构业务数据上执行，不修改用户测试账号的密码。

## 本次改动

- 超级管理员首次登录直接进入首页，可立即使用人员管理；其他四类角色仍须首次修改随机初始密码。
- 从 PR0.3 升级时，自动取消已有超级管理员的首次改密标记，仅递增受影响账号的身份版本；不重置密码，不修改其他用户的改密标记，重复启动不重复修改。
- 当前账号只读，当前密码仅显示固定、不可编辑的掩码，不包含旧密码，也不作为表单字段提交。用户只输入新密码及确认。
- 改密绑定服务端当前登录账号，要求最近 15 分钟内登录、有效会话和 CSRF；访问其他页面不延长这 15 分钟。超过时限需重新登录后再次打开改密页面。不能使用与原来相同的密码，改密后该账号原有会话全部失效。

## 已完成自动验证

- FoundationTest：183 项检查通过，原三表导入、填报、机构权限、事务、迁移和版本冲突等检查保持通过。
- HttpSmokeTest：124 项检查通过，真实隔离 HTTP 服务验证五角色登录分流、超管免改密、普通账号首次改密门禁、当前密码只读且无真实密码、新旧密码相同拒绝、两次密码不一致拒绝、CSRF、会话撤销，以及人员管理／机构隔离／导入导出回归。
- IdentityTest：53 项检查通过，覆盖超管初始状态和旧版本升级、密码保留、升级幂等、其他账号首次改密、改密 15 分钟边界、伪造会话拒绝、时钟回拨保护、旧身份版本撤销和原有账号权限检查。

合计 360 项检查通过。测试不包含真实麒麟运行或 Win7 IE 实机操作，亦未进行浏览器自动点击、截图验收。请在工作电脑使用脱敏数据安装测试。

离线安装器模拟测试已通过：首次安装、更新时完整旧版备份、迁移失败保留原目录、校验失败拒绝安装。模拟运行时仅验证安装控制流程，不代表已在麒麟实际运行 Java。

## 安装后重点核对

1. 超管登录直接进入首页，原有已修改密码仍可使用。
2. 创建一个测试人员账号，首次登录仍进入改密页；当前密码灰底不可编辑，只输入两次新密码。
3. 改密完成需重新登录，旧密码失效；人员管理和本支行数据权限不变。
4. 停止旧服务，使用新包 install.sh 更新同一安装目录，无需卸载；已有账号和业务数据保留。
