# 智慧信管 V0.3.0-rc.6

A1/B1/A2/B2 与 FEEDBACK-001（PR #10）已合并的联调测试版，schema 6。麒麟安装和运行完全离线，包内含 x86_64／aarch64 Java，不需要另装数据库或 Node。网页使用服务端 HTML 和本地资源，实际麒麟、Win7 旧 IE 仍需现场验收。

## 已开放功能

统一认证号登录、五角色人员管理和支行隔离；权限申请及审批、每次登录安全确认、通知和公共审计；一个入口批量上传包含负面闭环、多重预警、交叉违约三张子表的完整工作簿，提供新增／重复／更新汇总及保留／覆盖选择；操作员私人草稿、差异预览、提交和复核；正式完成率、年月季度区间筛选、三类风险清单及授权 Excel 导出、分行／超级管理员批量导出填报进度。草稿和待复核不进入正式统计或导出。

本版补充申请角色、重复认证号提示及上级管理员检查；人员管理可查看本人尚未修改的系统临时密码，逻辑删除保留历史；点击通知自动已读。上传无需填写月份／补充期次：负面闭环、多重预警优先使用表内时间顺序，缺失时尝试文件名；交叉违约必须按 L 列“违约首次出现时间”分月，缺失或日期无效整批报错。选择保留或覆盖后直接确认，无额外保存按钮或勾选；覆盖包括上传空白清空原值。无脚本时使用服务端二次确认。网页可下载统一空白模板。

三类清单都归入风险预警，首页四张统计卡可点击，支行分别显示三项填报进度；行内数据暂为空模块。明细默认每页 20 条，可选择 10／20／50 条，表格保留底部并新增联动顶部横向滚动条。进度导出包含所选时间／机构的三类正式统计，不受分页影响，支行角色不可导出进度。详见 [rc.3 调整与验证](docs/rc3-导入与风险展示调整.md)。

新增按“清单 × 来源期次”设置反馈截止日期，仅超级管理员和分行管理员可修改，对同一期全部支行生效。新设或修改必须晚于北京时间今天（最早明天），今天及过去日期由服务端拒绝；已到期的旧日期继续用于超期判定，仍可取消。首页显示本期剩余时间或超期天数；北京时间截止当天结束前有效，次日零点起正式未完成的记录标为“超期反馈”，黄色填报列不变。未设置日期不判超期，延期或取消立即按新配置计算，完成后恢复绿色；草稿和待复核不计完成。设置变更写入公共审计，不影响导入和业务版本，详见 [rc.4 说明](docs/rc4-反馈截止日期.md)。

超级管理员管理人员、查看全部业务并设置截止日期，不上传或填写；只有分行管理员上传。支行管理员、操作员和复核员只访问本支行。普通账号首次登录强制改密，超级管理员免首次改密。无风险按钮未实现；正式安全文案和其他行内模板待补充。

人员管理列表现直接显示“删除人员”按钮，点击后核对人员信息再确认。删除按停用处理，保留历史数据及认证号，不允许删除自己、同级／上级或越权支行人员；原待办责任保护仍生效。停用账号可通过修改人员状态恢复。见 [rc.6 说明](docs/rc6-人员删除入口.md)。本轮按用户要求制作 rc.6 麒麟离线测试包，旧 U 盘版本保留；请使用完整 rc.6 安装目录。

## 安装、启动、更新

把完整离线目录复制到麒麟本地，在该目录执行：

```bash
bash install.sh
cd "$HOME/ZhihuiXinguan-PR0"
./start.sh
```

沿用原测试安装路径以保留旧数据。更新前在旧服务窗口 Ctrl+C 停止，然后执行新 install.sh，无需卸载；若旧安装在其他位置，通过 INSTALL_DIR 指定原目录。详细步骤见安装包同级《安装测试说明.md》。

默认端口 2874，启动时可改；Ctrl+C 关闭，进入安装目录运行 `./start.sh status` 查看状态。访问 `http://麒麟电脑IP:端口/`，页面应显示 0.3.0-rc.6，`/health` 应显示 SCHEMA=6。

已有账号、密码和业务库保留，不重新初始化。空库才读取本地 bootstrap.local.properties；私人包可显式附带，未附带时参照空白 bootstrap.example.properties 在本机填写并限制文件权限。不要上传该文件或私人安装包到公共仓库。旧版公开历史中的初始密码仍应更换，本次升级不自动重置。

安装先校验并在暂存副本上迁移，再替换；完整旧版备份保留，不自动删除。失败停止并保留错误及备份，不删除迁移标记。新增 V006 截止日期迁移，V001～V005 不变。schema 6 不可直接交给 rc.3 或更早程序运行；升级后产生新数据时不可直接覆盖旧备份回退。

临时密码使用数据目录中的 `platform/initial-password.key` 加密；备份和恢复须同时保留整个数据目录以及该密钥和 `.bak` 副本。本人改密或停用后不再提供旧临时密码。主密钥遗失时尝试同一备份恢复；存在密文而主密钥与备份均缺失时拒绝启动，不静默生成替代密钥。请保全目录并联系维护人，勿删除数据库或密文绕过。

## 源码和本地检查

U 盘源码目录带源文件、文档、测试和锁定 JAR 缓存，不带 Git 历史、真实业务表、运行库或初始化凭据。开发需要 JDK 17+、Node 22+；Windows 安装模拟需要 Git for Windows 的 Bash：

```text
node tools/build.mjs --test --offline
node tests/install-smoke.mjs
```

普通构建支持源码快照；再次发布前应建立 Git 仓库并提交，以记录源码版本。GitHub CI 已按用户要求停用，今后使用本地测试，不擅自恢复。安装运行不需要上述开发工具。

HTTP 不加密，仅在获准隔离内网联调；正式推广前须落实行内网络传输保护和实际终端兼容验收。网页不加载外网资源，不调用大模型。
