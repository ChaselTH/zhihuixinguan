# 智慧信管 V0.2.2

智慧信管面向麒麟 Linux 局域网，可完全断网运行。服务器安装后，其他电脑只需使用浏览器访问；网页不加载互联网字体、脚本、图标或统计服务。

## 数据口径和功能

- 业务数据仅包括“触发多重预警排查清单”和“负面闭环”。`预警信息工行版.xlsx` 总表自动跳过。
- 首页、两类明细和支行页面均使用月度、季度、年度、自定义四种时间模式；选择一种后只显示该模式真正需要的条件。
- 多重预警 R—V 列、负面闭环 K—L 列为支行补充字段，不纳入风险数量和结构统计。
- 支行可在明细中填写补充字段，每张表只需点击一次“保存资料补充”即可批量保存当前页；长文本列使用适度加宽并自动换行。首页逐一显示全部机构和填报完成比例，并可点击支行查看两类明细。
- 首页四项总览展示多重预警、负面闭环、资料补充总进度和贷款余额；图表采用紧凑双栏排列，左侧趋势及分布图连续展示，右侧各支行填报进度独立延伸，避免长短模块产生大块空白。
- 两类清单均可按当前时间范围、机构和检索条件导出 `.xlsx`。
- 管理页面可多选 `.et`、`.xls`、`.xlsx` 批量上传。单文件最大 50 MB，一批最大 250 MB。
- 同一数据类型、同一时间段再次上传时替换原批次，其他月份和时间段保留。

## 首次离线安装

把整个 `zhihui-xinguan-offline-0.2.2-kylin` 文件夹从 U 盘复制到麒麟电脑本地硬盘，再打开终端：

```bash
cd /复制位置/zhihui-xinguan-offline-0.2.2-kylin
bash install.sh
```

默认安装目录为 `$HOME/ZhihuiXinguan`，支持 `x86_64/amd64` 与 `aarch64/arm64` 麒麟电脑。

## 启动、状态和关闭

```bash
cd "$HOME/ZhihuiXinguan"
./start.sh
```

启动时会询问端口，直接回车使用默认端口 `2874`；端口被占用时会要求重新选择。

- 查看状态：`./start.sh status`
- 关闭服务：回到启动终端按 `Ctrl+C`
- 首页：`http://<麒麟电脑IP>:端口/`
- 管理入口：`http://<麒麟电脑IP>:端口/admin`
- 初始管理员密码：`1999sth0520`

## 覆盖升级

1. 在旧版本启动终端按 `Ctrl+C`。
2. 确认旧安装目录运行 `./start.sh status` 显示“已停止”。
3. 进入新版本离线包，直接执行 `bash install.sh`。

安装器会保留原 `data/`，包括所有月份、批次、支行补充数据和管理员密码，无需卸载旧版本。

## Windows 7 / IE

页面采用服务端渲染，不依赖现代前端框架。推荐 Win7 使用 IE 9—IE 11，不要强制使用 IE7 文档模式。旧 IE 不支持一次多选文件时，可逐个上传；现代浏览器可直接多选批量上传。

## 安全说明

- 系统不连接外网，也不会上传数据到第三方。
- 管理密码使用 PBKDF2 加盐哈希保存。
- 管理上传带登录与请求校验；支行补充字段带独立页面请求校验。
- 安装目录和数据目录默认仅当前麒麟用户可读写。
- 若其他电脑无法访问，请按单位终端管理要求开放启动时选择的 TCP 端口。
