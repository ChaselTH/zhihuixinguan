# 智慧信管 V0.3.0-rc.2

A1/B1/A2/B2 与 FEEDBACK-001（PR #10）已合并的联调测试版，schema 5。麒麟安装和运行完全离线，包内含 x86_64／aarch64 Java，不需要另装数据库或 Node。网页使用服务端 HTML 和本地资源，实际麒麟、Win7 旧 IE 仍需现场验收。

## 已开放功能

统一认证号登录、五角色人员管理和支行隔离；权限申请及审批、每次登录安全确认、通知和公共审计；一个入口批量上传包含负面闭环、多重预警、交叉违约三张子表的完整工作簿，提供汇总预览与保留／覆盖／跳过；操作员私人草稿、差异预览、提交和复核；正式完成率、年月季度区间筛选、行内交叉违约及授权 Excel 导出。草稿和待复核不进入正式统计或导出。

本版补充申请角色、重复认证号提示及上级管理员检查；人员管理可查看本人尚未修改的系统临时密码，逻辑删除保留历史；点击通知自动已读。上传跨月文件时，优先准备明确的行内或文件名期次，避免填写一个覆盖所有文件的公共月份；存在冲突时会报错，整批不写入。多个月份的完整工作簿可在公共月份留空时按各自文件归属导入，网页可下载统一空白模板。

超级管理员管理人员、查看全部业务，不上传或填写；只有分行管理员上传。支行管理员、操作员和复核员只访问本支行。普通账号首次登录强制改密，超级管理员免首次改密。无风险按钮未实现；无截止字段，不显示超时红色；正式安全文案和其他行内模板待补充。

## 安装、启动、更新

把完整离线目录复制到麒麟本地，在该目录执行：

```bash
bash install.sh
cd "$HOME/ZhihuiXinguan-PR0"
./start.sh
```

沿用原测试安装路径以保留旧数据。更新前在旧服务窗口 Ctrl+C 停止，然后执行新 install.sh，无需卸载；若旧安装在其他位置，通过 INSTALL_DIR 指定原目录。详细步骤见安装包同级《安装测试说明.md》。

默认端口 2874，启动时可改；Ctrl+C 关闭，进入安装目录运行 `./start.sh status` 查看状态。访问 `http://麒麟电脑IP:端口/`，页面应显示 0.3.0-rc.2，`/health` 应显示 SCHEMA=5。

已有账号、密码和业务库保留，不重新初始化。空库才读取本地 bootstrap.local.properties；私人包可显式附带，未附带时参照空白 bootstrap.example.properties 在本机填写并限制文件权限。不要上传该文件或私人安装包到公共仓库。旧版公开历史中的初始密码仍应更换，本次升级不自动重置。

安装先校验并在暂存副本上迁移，再替换；完整旧版备份保留，不自动删除。失败停止并保留错误及备份，不删除迁移标记。新增 V005 迁移，V001～V004 不变。schema 5 不可直接交给 rc.1 或更早程序运行；升级后产生新数据时不可直接覆盖旧备份回退。

临时密码使用数据目录中的 `platform/initial-password.key` 加密；备份和恢复须同时保留整个数据目录以及该密钥和 `.bak` 副本。本人改密或停用后不再提供旧临时密码。主密钥遗失时尝试同一备份恢复；存在密文而主密钥与备份均缺失时拒绝启动，不静默生成替代密钥。请保全目录并联系维护人，勿删除数据库或密文绕过。

## 源码和本地检查

U 盘源码目录带源文件、文档、测试和锁定 JAR 缓存，不带 Git 历史、真实业务表、运行库或初始化凭据。开发需要 JDK 17+、Node 22+；Windows 安装模拟需要 Git for Windows 的 Bash：

```text
node tools/build.mjs --test --offline
node tests/install-smoke.mjs
```

普通构建支持源码快照；再次发布前应建立 Git 仓库并提交，以记录源码版本。GitHub CI 已按用户要求停用，今后使用本地测试，不擅自恢复。安装运行不需要上述开发工具。

HTTP 不加密，仅在获准隔离内网联调；正式推广前须落实行内网络传输保护和实际终端兼容验收。网页不加载外网资源，不调用大模型。
