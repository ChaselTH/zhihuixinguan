# 智慧信管 V0.3.0-pr0.7

公共基础测试版，继续采用 Java 本地服务、服务端 HTML 和本地静态资源。麒麟安装／启动完全离线，不需要另装数据库、Node 或联网下载。完整安装包自带 x86_64 与 aarch64 Java。

PR0.7 为公共基础合并测试版，新增私人草稿、差异预览、不可变提交单、原子复核／退回／直接确认、个人通知及 V002 顺序升级；尚未接入工作流网页。本轮合并后先交付用户测试，A1/B1 等测试反馈后再开始。API 和后续分工见 [交接说明](docs/workflow-platform-api.md)，包内 SOURCE_COMMIT 可核对源码；以下安装流程不代表已完成麒麟实测。

## 当前范围

添加／修改人员的机构选择随角色联动：分行管理员自动归属分行，不显示机构选择；支行管理员、操作员和复核员选择所属支行。下拉框只列出有权管理的支行，不再包含“分行”选项。分行归属由后台确定，支行角色仍须通过机构权限校验；切换角色时保留已选支行。

三个独立上传入口：负面闭环、多重预警、交叉违约；提供无业务数据的模板；新表头黄色字段任一非空即完成。固定九家支行，保留月／季／年／自定义范围、统一保存和 Excel 导出。基础数据库实现稳定记录编号、版本冲突检测、事务审计、旧数据迁移和重复导入保留／覆盖确认。

本版已开放统一认证号登录、五角色菜单及机构数据隔离，以及人员新增、查看、修改、停用／恢复、重置密码。初始超级管理员的认证号及密码只从应用目录的 bootstrap.local.properties 读取；账号库非空时完全忽略该配置，不重复初始化、不重置已有密码。超级管理员免首次改密，其他新建／重置账号仍须首次改密。旧 /admin 独立页面和旧密码登录接口已停用，旧 auth.properties 不再用于认证。

修改密码页面的当前账号只读，当前密码显示固定只读掩码，不包含真实密码，无需重复输入；仅输入新密码及确认。后端要求本账号最近 15 分钟内登录、有效会话及 CSRF 校验，超时需重新登录后再打开改密页面；新密码不能与原密码相同。修改成功后该账号所有旧会话失效。账号库只保存加盐哈希，页面不回填或还原当前密码。初始化本地配置须按凭据保管，不能提交到 GitHub；源码及测试不带真实认证号、密码或它们的哈希。

账号管理和业务权限严格区分：超级管理员管理人员、查看全部数据，不上传和填写；分行管理员可更新数据；支行管理员、操作员、复核员仅本支行范围。操作员草稿／提交和复核审批、权限申请、通知、安全提示确认页尚未开放，操作员当前只读和导出，不能直接修改正式数据。本版不做无风险按钮和反馈超时标色，暂不用于正式审批业务。

## 安装、启动、更新

复制完整离线包文件夹到麒麟本地，进入该文件夹执行：

```bash
bash install.sh
cd "$HOME/ZhihuiXinguan-PR0"
./start.sh
```

首次空库启动前，将应用目录的 `bootstrap.example.properties` 复制为 `bootstrap.local.properties`，在本机填写 `auth_number` 和 `password`，并限制文件权限（麒麟可用 `chmod 600 bootstrap.local.properties`）。私人离线包可由打包时显式附带本地配置，安装器自动放入应用目录；通用包只含空白示例。配置缺失或无效时，空库拒绝启动，不生成默认账号。更新已有账号库不要求保留初始化文件，旧密码不会被配置覆盖。

默认与旧正式版并排安装。端口默认 2874，启动时可改；`./start.sh status` 查状态，Ctrl+C 停止。统一入口 `/login`，登录后按角色显示人员管理和数据更新按钮。更新已有 PR0 目录保留业务数据；首次从旧单密码版本升级需要本地配置建立超级管理员，旧单密码不迁为新身份密码。PR0.3 以后更新保留已有账号和密码，不重复初始化。

更新同一个 PR0 目录只需先停服务，再执行新包 install.sh，无需卸载。对旧正式目录原地升级需要明确设置 `INSTALL_DIR`。安装器先复制并迁移暂存数据，成功才替换目录；完整旧版备份保留，不自动清除。详细步骤、风险与验收清单见离线包的《安装测试说明.md》，源码中为 `docs/PR0-安装测试说明.md`。

## 开发及安全边界

JDK 17+、Node 22+：`node tools/build.mjs --test`；已有依赖时加 `--offline`。依赖版本和哈希见 dependencies.lock.json。后续双 AI 开发约定见 [公共接口与分工](docs/foundation-contracts.md) 和 [B1 工作流就绪清单](docs/B1-工作流就绪清单.md)：先将公共基础和公共事务补丁分别合入 main，再从同一提交并行。main 是共同开发基线，不等于实机验收通过的发布包。

网页不加载外网资源，无大模型调用。密码用加盐 PBKDF2 哈希，管理及保存带会话与 CSRF 校验，数据库不开放远程服务。HTTP 不提供传输加密，仅在获准隔离内网测试；正式多用户部署需按单位要求核验传输安全。旧 IE 可分批或使用第二个文件框上传；麒麟／Win7 IE 实机兼容须由测试确认。

本地定制离线包：打包脚本通过可选 `-BootstrapConfig <本地配置路径>` 显式加入初始化文件，不会自动收集项目内的私有配置。带该参数产生的整个目录、压缩包及 U 盘副本都属于私人包，不得上传 GitHub 或公开 Release。旧版公开历史中的初始密码仍应更换，本次不会自动重置账号或改写历史。
