# 智慧信管

智慧信管是面向局域网的企业风险预警与闭环跟踪系统，采用 Java 本地服务、服务端 HTML 和本地资源，面向麒麟断网部署及 Windows 7 旧 IE 访问。当前为公共基础测试版，真实麒麟和最低 IE 版本仍需实机验收。

主要能力包括：

- 统一认证号登录、五角色人员管理、会话撤销与支行数据隔离
- 多重预警、负面闭环及交叉违约三表展示与 Excel 导出
- 月度、季度、年度及自定义月份区间筛选
- 支行资料补充、批量保存和完成进度统计
- 仅分行管理员可使用三个独立入口导入 `.et`、`.xls`、`.xlsx`，重复数据先预览再确认
- `install.sh` 覆盖升级和 `start.sh` 交互式启动

安装、升级和数据口径说明请查看 [README_zh.md](README_zh.md)。

后续开发先阅读 [公共接口与分工](docs/foundation-contracts.md)、[需求方案](docs/plan-v0.3.0.md) 和 [B1 工作流就绪清单](docs/B1-工作流就绪清单.md)。协作顺序统一为 PR0.6 合入 main → 公共事务补丁合入 main → A/B 从同一提交并行；这是开发安排，不是已经合并或投产的声明。权限申请、通知、安全提示确认、操作员草稿及复核审批尚未完成；操作员目前只读和导出。公共补丁未通过就绪清单前，不开放 B1 正式业务开发。

## 数据安全

真实业务表格、运行数据库、原始内部需求／合规材料、个人初始化配置和离线运行时包不得提交。`docs/` 中仅保留技术方案、接口契约和脱敏测试说明。源码及通用构建不含初始化账号或密码；首次空库启动使用 Git 忽略的 `bootstrap.local.properties`，参考空白 `bootstrap.example.properties`。旧版公开历史中的初始密码不会因本次移除而恢复保密，应更换已暴露密码。
