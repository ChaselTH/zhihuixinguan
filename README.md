智慧信管是面向局域网的企业风险预警与闭环跟踪系统，采用 Java 本地服务、服务端 HTML 和本地资源，面向麒麟断网部署及 Windows 7 旧 IE 访问。当前为完整流程联调测试版，真实麒麟和最低 IE 版本仍需实机验收。

主要能力包括：

- 统一认证号登录、五角色人员管理、会话撤销与支行数据隔离
- 权限申请及分级审批、每次登录安全确认、个人未读通知、授权范围操作记录
- 多重预警、负面闭环及交叉违约三表展示与 Excel 导出
- 月度、季度、年度及自定义月份区间筛选
- 支行资料补充、私人草稿、差异提交、复核及完成进度统计
- 首页只列正式未完成记录；完整清单的完成状态、时间、机构及搜索与导出一致；正式值与流程状态分开显示
- 交叉违约归入风险预警；行内数据等待后续模板
- 仅分行管理员可统一批量导入包含三张子表的 `.et`、`.xls`、`.xlsx` 工作簿；本人暂存、保留／覆盖、冲突检查后整批确认
- 每类清单、每个来源期次独立设置反馈截止日期；首页倒计时、超期反馈标红及筛选
- 可定位到文件／Sheet／行／列的错误、版本化模板说明及服务端授权正式 Excel 导出
- `install.sh` 覆盖升级和 `start.sh` 交互式启动

安装、升级和数据口径说明请查看 [README_zh.md](README_zh.md)。

## 数据安全

真实业务表格、运行数据库、原始内部需求／合规材料、个人初始化配置和离线运行时包不得提交。`docs/` 中仅保留技术方案、接口契约和脱敏测试说明。源码及通用构建不含初始化账号或密码；首次空库启动使用 Git 忽略的 `bootstrap.local.properties`，参考空白 `bootstrap.example.properties`。旧版公开历史中的初始密码不会因本次移除而恢复保密，应更换已暴露密码。
