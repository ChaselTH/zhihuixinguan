# 智慧信管

智慧信管是面向局域网的企业风险预警与闭环跟踪系统，支持在麒麟 Linux 环境完全断网部署，并兼容 Windows 7 上的旧版 IE 浏览器访问。

主要能力包括：

- 多重预警和负面闭环数据展示、统计与 Excel 导出
- 月度、季度、年度及自定义月份区间筛选
- 支行资料补充、批量保存和完成进度统计
- 管理员批量导入 `.et`、`.xls`、`.xlsx` 表格
- `install.sh` 覆盖升级和 `start.sh` 交互式启动

安装、升级和数据口径说明请查看 [README_zh.md](README_zh.md)。

## 数据安全

仓库不包含任何业务表格、运行数据、需求/合规材料或离线运行时安装包。请勿将真实客户数据提交到 Git 仓库。
